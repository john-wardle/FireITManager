# FireIT Manager User Documentation

This folder contains user-facing documentation for the current FireIT Manager prototype.
It is written for ITSS users, incident technology staff, and new project contributors who
need to understand how the application is meant to be used.

These documents describe the current Python/PySide desktop prototype. They should be
updated as the project moves toward the planned live, multi-user C#/.NET incident system.

## Current Prototype Scope

The current desktop app can model a single incident workspace with:

- Incident metadata.
- Camps and buildings.
- Devices, assets, and personnel.
- Network membership and site-map visualization.
- Basic reports and validation.
- Local JSON save/load.

The current prototype is not yet a simultaneous multi-user system. The planned target is
an incident-local server with desktop and mobile/tablet clients.
